# Warehouse Executive Dashboard

ระบบวิเคราะห์คลังสินค้าสำหรับการสาธิตและฝึกอบรม สร้างด้วย HTML, CSS และ JavaScript

## การใช้งาน
เปิด `index.html` ใน Chrome หรือ Edge หรือเผยแพร่ผ่าน GitHub Pages

## เผยแพร่ผ่าน GitHub Pages
1. สร้าง Repository ใหม่บน GitHub ชื่อ `warehouse-executive-dashboard` และตั้งค่า Public
2. อัปโหลดไฟล์ `index.html` และ `README.md` ลงสาขา `main`
3. ไปที่ **Settings > Pages > Build and deployment**
4. เลือก **Deploy from a branch**, Branch `main`, Folder `/(root)` และกด **Save**
5. เมื่อ GitHub Pages เผยแพร่เรียบร้อย ให้เปิด URL ที่แสดงใน Settings > Pages

## ข้อมูล
ภายใน HTML มีข้อมูลจำลองฝังอยู่แล้ว และรองรับการนำเข้า CSV ใหม่จากหน้า Dashboard

> หมายเหตุ: หน้าเว็บเรียก Google Fonts จากอินเทอร์เน็ตเพื่อแสดงฟอนต์ Prompt; ถ้าออฟไลน์ ระบบจะใช้ฟอนต์สำรอง
